# 공실은 늘어도 임대료는 그대로다
### 골목상권이 스스로 회복하지 못하는 이유 — 서울 59개 상권 데이터 분석

**1팀 · 나건호** | SeSAC 데이터분석 교육과정 Final Project

---

## 📌 프로젝트 배경

> "공실이 늘어도 임대료는 좀처럼 내려가지 않는다" — 이코노미21, 2026.06.02

전국 상가 공실률이 13%를 넘어선 가운데, 공실 증가가 임대료 하락으로 이어지지 않는다는 현장 기사를 계기로 이 문제의식이 서울 골목상권 데이터에서도 실제로 나타나는지 확인하고, 임대료가 내려가지 않는 이유를 데이터로 분석했다.

공인중개사로 근무한 경험을 바탕으로, 정량 데이터가 설명하지 못하는 부분은 현장 지식으로 보완했다.

## 🎯 분석 목표

1. 공실률 추이 확인 — 서울 59개 상권의 공실률이 실제로 증가하는 추세인지 확인
2. 임대료 경직성 검증 — 공실이 늘어난 상권에서 임대료가 어떻게 변화하는지 검증
3. 원인 규명 — 공실률이 증가했음에도 임대료가 내려가지 않는 이유를 설명
4. 역설 상권 식별 — 공실↑·임대료→·순영업소득↑이 동시에 나타나는 상권을 찾아 회복 불능 구조를 확인

## 🗂 데이터

- **출처**: 한국부동산원 「상업용부동산 임대동향조사」, KOSIS 국가통계포털
- **범위**: 서울 59개 상권 × 7개 분기(2024.3/4 ~ 2026.1/4)
- **데이터셋**: 공실률(%), 임대료(천원/㎡), 순영업소득(천원/㎡) 3종

## 🔧 전처리

1. **지역 필터링**: 전국 17개 시도 → 서울 59개 상권만 추출
2. **항목 필터링**: 임대수입·기타수입·운영경비 등 5개 항목 중 순영업소득만 추출
3. **병합**: 상권명 + 분기 기준으로 3개 CSV를 하나의 데이터프레임으로 병합 (413행)

## 📊 핵심 분석 결과

| 지표 | 결과 |
|---|---|
| 서울 상권 평균 공실률 | 4.91% → 5.55% (7개 분기 연속 상승) |
| 공실 증가 상권 중 임대료 유지·상승 비율 | 92.9% (28개 중 26개) |
| 진짜 임대료 경직 상권(28개 중) | 8개 — 나머지 18개는 임대료 자체가 상승 |
| 역설 상권 8곳 순영업소득 변화율 | +50.1% (비교군 +19.0%) |
| 역설 상권 8곳 운영경비율 변화 | 40.0% → 12.7% |

**역설 상권 8곳**: 독산/시흥, 숙명여대, 신촌/이대, 연신내, 신림역, 미아사거리, 오류동역, 청량리

## 💡 해석 — 임대인의 버티기

데이터로 증명되는 부분과 그렇지 않은 부분을 명확히 구분했다.

- **데이터로 증명됨**: 역설 상권의 순영업소득 증가는 임대수입 감소(-2.8%)가 아니라 운영경비 절감(운영경비율 40.0%→12.7%)에서 비롯되었다.
- **데이터로 증명 안 됨(한계)**: 왜 운영경비가 줄었는지는 개별 건물 단위 데이터 없이는 확인할 수 없어 후속 연구 과제로 남긴다.
- **현장 해석(정량 데이터 아님)**: 상가 임대료를 공식적으로 낮추면 향후 매각 감정평가·담보대출 한도의 기준이 낮아지므로, 임대인은 단기 공실을 손실이 아니라 자산가치를 지키기 위한 비용으로 받아들이는 경향이 있다.

## ✅ 결론

서울 골목상권 59곳 중 28곳에서 공실률이 올랐지만, 그중 26곳(93%)은 임대료가 유지되거나 오히려 올랐다. 임대료가 진짜로 그대로인 8곳만 비교해도 순영업소득은 줄지 않고 오히려 늘었다. 공실이 늘어도 가격은 스스로 조정되지 않았다 — 골목상권의 회복은 시간이 지난다고 저절로 오지 않는다.
